# WebPulse

WebPulse 是一个基于 Chrome Manifest V3 的本地浏览行为分析扩展，用来统计你在当前前台标签页上的停留时长、站点排行、周报/月报和成就进度。

## 功能

- Popup 快览：今日时长、站点数、成就、活跃节奏、最近 7 天、今日站点排行
- 历史仪表盘：日历式浏览历史、趋势图、热力图、站点排行、周报/月报
- 站点详情页：单站点的分日、分时、分类和访问节奏分析
- 成就系统：经验值、等级、进度和解锁状态
- 设置页：主题、默认仪表盘范围、清空本地数据
- 导出：仪表盘支持导出 CSV / JSON

## 统计规则

- 只统计当前浏览器窗口中正在前台显示的标签页
- 切换标签、切换窗口或关闭窗口时，当前计时结束
- 不依赖 `idle` 空闲检测，只按页面是否仍然处于前台来计时
- 所有数据只保存在本地浏览器，不上传服务器

## 项目结构

- `src/background`：后台计时与数据聚合
- `src/popup`：弹窗快览
- `src/dashboard`：历史仪表盘
- `src/site`：站点详情页
- `src/achievements`：成就页
- `src/options`：设置页
- `src/shared`：共享类型、时间、存储和聚合逻辑
- `public/manifest.json`：扩展清单

## 本地开发

```bash
pnpm install
pnpm build
```

开发时可以用：

```bash
pnpm dev
```

## 安装到 Chrome

1. 执行 `pnpm build`
2. 打开 `chrome://extensions`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目里的 `dist` 目录

## 使用

- 点击扩展图标打开 Popup
- 用快捷键 `Ctrl+Shift+Y` 打开历史仪表盘
- 在仪表盘里切换周报 / 月报 / 全部历史
- 从站点排行进入某个站点的详情页
- 在设置页修改主题和默认历史范围

## 权限

当前只申请了：

- `tabs`
- `storage`
- `alarms`

没有申请 `host_permissions`，也没有把历史数据发到远端。

## 说明

- 当前版本的数据都存储在本机浏览器的 `IndexedDB` 和 `chrome.storage.local`
- 如果你清空浏览器本地数据，统计记录也会一起消失
- 仪表盘、站点页和成就页都属于本地页面，不依赖外部服务
